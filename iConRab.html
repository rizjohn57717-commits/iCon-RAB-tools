Cara Install iCon RAB di HP

Tanpa Play Store / App Store (100% Gratis)

HP Android (Google Chrome)
  1. Buka file/link iCon RAB di browser Google Chrome.
  2. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas browser.
  3. Pilih "Tambahkan ke Layar Utama" atau "Instal Aplikasi".
  4. Tekan Tambahkan / Instal — ikon iCon RAB langsung muncul di menu HP!
iPhone / iPad (Safari)
  1. Buka link iCon RAB menggunakan browser Safari.
  2. Ketuk tombol Bagikan / Share (ikon kotak panah ke atas di bawah).
  3. Geser ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah di pojok kanan atas.

Tips Pro: Upload file icon-rab.html gratis ke app.netlify.com/drop atau tiiny.host (cukup 30 detik, tanpa coding) agar data tersimpan permanen dan bisa diinstal layar penuh.
